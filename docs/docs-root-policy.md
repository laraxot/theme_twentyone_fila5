# Docs Root Policy

## Regola

Per moduli e temi la documentazione viva sta in `docs/`.

La cartella `_docs/` non e' un root valido e non deve essere introdotta neppure come staging temporaneo.

## Motivo

Usare un solo root documentale riduce rumore, duplicazioni e ambiguita' durante fix, review e debugging.
