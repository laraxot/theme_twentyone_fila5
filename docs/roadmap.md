## 🎯 THEME OVERVIEW

Il tema **TwentyOne** è il tema dedicato all'interfaccia amministrativa della piattaforma FixCity, progettato per fornire un'esperienza ottimale per operatori, amministratori e gestori del sistema.

### 🏗️ Architettura Tema
```
TwentyOne Theme
├── 🎨 Admin Design System
│   ├── Filament Components
│   ├── Admin Color Palette
│   ├── Typography System
│   └── Spacing System
│
├── 🧩 Admin Components
│   ├── Dashboard Widgets
│   ├── Data Tables
│   ├── Form Components
│   └── Navigation Components
│
├── 📊 Data Visualization

    └── Custom Actions
```
