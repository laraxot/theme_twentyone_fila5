# BMAD Method - Metodologia Completa per Agenti AI

## 🎯 Filosofia BMAD - Build More Architect Dreams

**BMAD Method** è una metodologia agile guidata dall'AI per sviluppo software con intelligenza adattiva che si scala da bug fixes a sistemi enterprise.

**Principi Fondamentali:**
- **AI Intelligent Help**: Agenti esperti guidano processo strutturato
- **Scale-Domain-Adaptive**: Adatta profondità pianificazione alla complessità progetto
- **Structured Workflows**: Basati su best practices agile
- **Specialized Agents**: 12+ esperti (PM, Architect, Developer, UX, Scrum Master)
- **Party Mode**: Collaborazione multi-agente in sessioni unificate

## 📦 Moduli Disponibili

| Modulo | Scopo |
|--------|--------|
| **BMM** | Core framework con 34+ workflow |
| **BMB** | Creazione agenti custom e workflow |
| **TEA** | Risk-based test strategy e automazione |
| **BMGD** | Game development workflows (Unity, Unreal, Godot) |
| **CIS** | Innovation, brainstorming, design thinking |

## 🚀 Installazione e Configurazione

```bash
# Installazione BMAD
npx bmad-method install --modules bmm,bmb,tea,gds --yes

# Verifica installazione
bmad-help

# Comandi principali
bmad-help                    # Guida contestuale
bmad-new-project            # Inizializza progetto
bmad-discuss-phase [N]      # Discussione fase
bmad-plan-phase [N]         # Pianificazione
bmad-execute-phase [N]      # Esecuzione
bmad-verify-work [N]        # Verifica UAT
bmad-complete-milestone     # Archivia milestone
```

## 🏆 Confronto BMAD vs GSD

### BMAD (Strutturato, Enterprise)
- ✅ Pianificazione approfondita
- ✅ Scale adattiva intelligente
- ✅ Team multi-agente
- ✅ Workflow formalizzati
- ❌ Overhead per task semplici

### GSD (Veloce, Pragmatico)
- ✅ Esecuzione rapida
- ✅ Context management ottimale
- ✅ Spec-driven development
- ✅ Zero overhead
- ❌ Meno strutturato per progetti grandi

## 🎯 Best Practices per Predict

1. **BMAD per architetture**: Nuove funzionalità complesse
2. **GSD per implementazioni**: Bug fixes, piccole modifiche
3. **Party Mode**: Discussioni tra agenti specializzati
4. **Milestone completi**: Verifica qualità prima commit
5. **Documentazione**: Aggiorna docs dopo ogni milestone
