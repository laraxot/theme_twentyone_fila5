# GSD Method - Get Shit Done per Agenti AI

## 🎯 Filosofia GSD - Get Shit Done

**GSD** è un sistema meta-prompting, context engineering e spec-driven development leggero e potente per Claude Code, Codex, Cursor e altri IDE AI.

**Principi Fondamentali:**
- **Context Rot Prevention**: Previene degradazione qualità come AI riempie context window
- **Spec-Driven Development**: Sviluppo guidato da specifiche chiare
- **Lightweight & Powerful**: Sistema semplice ma estremamente efficace
- **AI-First Workflow**: Ottimizzato per collaborazione AI-umano

## 📦 Installazione e Configurazione

```bash
# Installazione GSD
npx get-shit-done-cc@latest
```

## 🏆 Confronto GSD vs BMAD

### GSD (Veloce, Pragmatico)
- ✅ Esecuzione immediata
- ✅ Zero overhead cerimonie
- ✅ Context management ottimale
- ✅ Perfetto per task isolati
- ❌ Meno struttura per progetti grandi

### BMAD (Strutturato, Enterprise)
- ✅ Pianificazione completa
- ✅ Scale adattiva
- ✅ Team collaboration
- ✅ Lifecycle completo
- ❌ Overhead per task semplici

## 🎯 Best Practices per Predict

1. **GSD per implementazioni**: Bug fixes, piccole features

3. **Combinazione ottimale**: BMAD planning + GSD execution
4. **Context awareness**: Mantieni focus su task specifici
