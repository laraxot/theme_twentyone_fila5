## Processo di Analisi Errori

### 1. Identificazione
- Analizzare l'errore specifico
- Identificare il contesto
- Mappare le dipendenze
- Verificare la documentazione esistente
- Controllare le best practices

### 2. Analisi Causa Radice
- Perché è stato fatto l'errore?
- Quali assunzioni erano errate?
- Quali best practices non sono state seguite?
- Quali parti della documentazione erano incomplete?
- Quali controlli preventivi mancavano?

### 3. Impatto
- Su quali componenti ha impatto?
- Quali file sono coinvolti?
- Quali test sono necessari?
- Quali documenti vanno aggiornati?
- Quali best practices vanno riviste?
